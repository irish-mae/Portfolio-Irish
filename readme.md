# Irish Labis Tagaylo — Portfolio

A responsive, six-page static portfolio site designed for recruiters. The source is plain HTML, CSS, and JavaScript; no build tools or dependencies are required.

## Preview

Open `index.html` in a browser. For the best experience, use a small local web server from this folder, such as `python -m http.server 8000`, then visit `http://localhost:8000`.

## Pages

- `index.html` — home and selected work
- `about.html` — profile, approach, education, certifications
- `work.html` — five case studies
- `experience.html` — professional and leadership timeline
- `skills.html` — evidence-based capabilities
- `contact.html` — contact links and résumé download placeholder

## Before publishing

Search the HTML files for `[ADD-` and `[Name]` / `[DATES]` placeholders. Add the verified SK barangay and dates, email, LinkedIn, GitHub, and résumé PDF (`resume.pdf`). Replace the conceptual case-study visuals and evidence prompts with approved project photos, screenshots, diagrams, and documents. Confirm any tool names marked `[verify]` and the location line on the contact page. Avoid publishing confidential client data.

The content reflects details available in the referenced conversation; the original résumé file was not available in this workspace for direct verification.
